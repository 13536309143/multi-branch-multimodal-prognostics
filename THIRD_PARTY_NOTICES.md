## Method and synthetic benchmark

Zhe Yang, Piero Baraldi, Enrico Zio. *A multi-branch deep neural network model for failure prognostics based on multimodal data*. Journal of Manufacturing Systems 59 (2021), 42–50. https://doi.org/10.1016/j.jmsy.2021.01.007

Original dataset source: https://www.lasar.polimi.it/?page_id=2970

Dataset mirror/card: https://huggingface.co/datasets/GeorgeWJJ/steam-generator-multimodal-prognostics

The local raw dataset documentation requests citation but does not state an explicit dataset license; neither did the linked benchmark page when checked on 2026-10-14. The mirror preserves attribution and documents unspecified upstream terms. This project's MIT code license does not grant rights over third-party raw data. Images shown as raw examples originate from this benchmark. Scientific result plots and the architecture diagram were generated by the project.

## GloVe pretrained vectors

Jeffrey Pennington, Richard Socher, Christopher D. Manning. *GloVe: Global Vectors for Word Representation* (2014).

Source: https://nlp.stanford.edu/projects/glove/

The original GloVe 6B 100-dimensional pretrained vectors are distributed under the Open Data Commons Public Domain Dedication and License v1.0: https://opendatacommons.org/licenses/pddl/1-0/

`assets/glove.6B.100d.subset.json` contains only relevant vector entries from that original release, with provenance/CRC metadata. Randomly initialized missing-word embeddings are generated at runtime; they are not represented as pretrained vectors.
